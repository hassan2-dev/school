# دليل التسليم — نظام درجات المدارس

## ماذا تستلم؟

منتج Web App جاهز للعرض والتشغيل المحلي، مع:

- واجهة عربية RTL كاملة
- Seed بيانات حقيقي (مدرسة + صفوف + شعب + مواد + طلاب + درجات)
- ملفات Excel تجريبية للرفع والتحليل
- Pipeline: Upload → Parse → Detect → Match → Validate → Review → Import
- قواعد Firestore / Storage
- Cloud Functions stubs
- بدون NestJS — Firebase-first

---

## تشغيل خلال دقيقة

```bash
cd web
npm install
npm run generate:samples
npm run dev
```

1. افتح الرابط الذي يظهر (مثلاً http://localhost:5174)
2. اضغط **دخول تجريبي بدون Firebase**
3. ستجد لوحة التحكم مملوءة ببيانات Seed
4. من قائمة **الـ Seed** نزّل ملفات Excel التجريبية
5. من **رفع الملفات** ارفعها دفعة واحدة وجرّب المراجعة والاستيراد

---

## محتوى الـ Seed

| العنصر | المحتوى |
|--------|---------|
| المدرسة | مدرسة عبد الله الرضيع الابتدائية |
| الأعوام | 2024/2025 (نشط) + 2025/2026 |
| الصفوف | الأول → السادس (Dynamic + maxScore 10/100) |
| الشعب | أ/ب/ج (ود للصفوف الأولى) |
| المواد | لكل صف مواده الخاصة |
| طلاب الأول أ | 37 طالب مع درجات |
| طلاب الخامس ب | 32 طالب مع سعي + امتحان + نهائية |
| Templates | قراءة / رياضيات خامس / إنكليزي |
| Import log | عملية استيراد مكتملة للعرض |

---

## مسارات العرض السريع للعميل

1. `/` لوحة التحكم والإحصائيات  
2. `/school` شجرة الصفوف والشعب  
3. `/section/sec_1_أ_year_2024_2025` شعبة الأول أ  
4. `/section/sec_5_ب_year_2024_2025` شعبة الخامس ب  
5. `/upload` ثم `/import/review`  
6. `/reports` Excel + طباعة  
7. `/seed` إدارة وإعادة تحميل البيانات  

---

## ربط Firebase (إنتاج)

1. انسخ `web/.env.example` → `web/.env` واملأ المفاتيح  
2. انشر القواعد من `firebase/`  
3. (اختياري) ارفع الـ Seed إلى Firestore:

```bash
# بعد وضع service account
set GOOGLE_APPLICATION_CREDENTIALS=path\to\serviceAccount.json
cd web
npx tsx scripts/seed-firestore.ts
```

ملاحظة: سكربت Firestore يحتاج `firebase-admin` مثبتاً في بيئة الـ seed.

## رسالة للمبرمج / العميل

> النظام مصمم Dynamic بالكامل: الصفوف، الشعب، المواد، مكونات التقييم، وحدود الدرجات تأتي من البيانات وليس من Hard-code في الواجهة. الـ Seed مجرد قيم ابتدائية قابلة للتعديل.
